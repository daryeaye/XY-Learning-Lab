## Class-removal data contract

These mutations happen only after the teacher clicks Delete from selected classes. Deployment performs no deletion, migration or backfill.

- Normal assignments detach only selected assignment/class links, remove selected class students from explicit assignment selection, update the primary class to a remaining class and remove obsolete class-opening entries. The pre-existing deletion semantics for scores apply only to selected classes: remove their grades/history, clear their attempt grades and response credit. Other classes' grades, attempts, responses, reservations and assignment settings remain intact. Final class removal marks the assignment DELETED. Old clients that omit classIds retain full-deletion behavior.
- Comic-Con removes selected class links and updates the draft class list with an optimistic updated-value guard. Work, allocations, snapshots, comics and media remain archived; other classes retain access. Final removal marks the project deleted and resolves its assignment notifications. Progress queries now require an active assignment/class link, so detached classes do not retain visible project progress.
- Native assessments remove selected class IDs and their explicit student selection/opening entries, preserving all attempt records. Final removal marks the assessment deleted. An optimistic record comparison rejects concurrent changes. The separate unpublished, unstarted **Delete This Draft** action retains its V10 atomic state/attempt guard.

No class, roster, student account, reward receipt, point balance or R2 media purge was added. Archive Class/export/permanent purge remains deliberately deferred.
