## Teacher UI changes and preferences

- Group related navigation in a shared **pill/segmented container**, with an inset selected pill, consistent height and compact labels. Applied to the seven teacher header destinations, three notification categories and Boards Up Yes/No. Existing labels, Student view's new-tab semantics, focus/keyboard behavior and unread red dots remain. At narrower widths the header navigation takes a full row; smaller screens scroll within the capsule. Student assignment category shapes and unrelated action buttons were not redesigned. The owner's latest capsule request supersedes older rectangular teacher-header/notification descriptions. See Apple's [segmented-control guidance](https://developer.apple.com/design/human-interface-guidelines/segmented-controls) for the reference pattern; no specific iOS release availability is assumed.
- Prefer **compact, aligned controls with clear hierarchy**, rather than large disconnected boxes. In ordinary assignment Advanced Settings, Late Credit % and the notification-days sentence share one wrapping row. Numeric controls have a centered three-digit width. The same min/max/value handlers and saved payload fields remain.
- In project/creator navigation, **Back + Save Draft go left; Next/continue goes right**, on every step. Avoid a redundant Home button or repeated Save control at the top. Put content actions near the content heading (for example Project 1 Add a problem beside its pool heading); retain V18's compact class/student picker and two-digit attempts/votes controls.
- Keep the established fonts: **Source Sans 3 for normal interface copy/controls, Libre Baskerville for teacher headings, and the existing MathLive/math and student/game fonts**. Use readable, consistent sizing, avoiding oversized editor gaps or mismatched action buttons. V20 does not replace the platform font system or unrelated original fallback behavior.
- Teacher reply/message lines now use **1.3 line spacing**. The shared large-editor rule had forced every separate message math-field line to **100px** high; scoped message styles reset that minimum and internal padding. Actual Shift+Enter produced two **28.594px** lines with a **22px** host font and **28.6px** line height, and a fictional two-line reply retained its line break on save/reopen. Larger mathematical content can grow naturally. Native Work/Answer editors and serialization/formatting functions were not changed globally.
- The terminal report actions **Mark Resolved and Grant Credit**, **Mark Resolved without granting credit**, and **Write another message** now share one row at **14px / 36px** height, with equal styling dimensions and horizontal access when needed. They remain separate actions with their original handlers/permissions. Compose/cancel/send polling, race guards and conversation history remain.

These preferences summarize the latest direction and supplement V18; do not delete earlier handoffs merely because this summary exists.
