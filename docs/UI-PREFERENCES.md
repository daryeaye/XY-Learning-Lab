# Compact interface preferences

The owner's October27,2026 direction applies to every future new or changed XY Learning Lab interface unless explicitly overridden.

- Keep titles, button labels and subtitles on one line. Use concise wording and available width; preserve complete meaningful text and accessible names. Multiple controls may move between rows on narrow screens while each label remains one line.
- Keep controls compact, with even gaps, aligned checkboxes/text and aligned labels/inputs. Do not add duplicate headings, subtitles, Description labels or unnecessary explanatory copy. Problem paragraphs and actual work may still use multiple lines.
- Check integrated desktop and phone layouts. Inherited label grid/column/display rules can override an isolated flex direction; measure the actual control/text positions. Keep popovers inside the viewport.
- Preserve an explicit font-size request. V32's Boards timer buttons get wider while their font sizes remain unchanged. Use existing measured single-line fitting where that feature already supports it.
- Current teacher wording is **Add Scaffolding**. Eligible new digital-builder/review choices default checked; retain explicit saved choices, existing snapshots, per-level maps, worksheet exclusion and Save/Cancel behavior.
- Factoring uses the existing native main/abc keyboard. Field focus tracks the target; its button opens it manually. Keep physical input, math templates and actual saved/reopened values.
- Reuse actual student components in teacher demonstration paths, preserving assignment restrictions and release/completeness gates. Demonstrations stay temporary and must never write to real student accounts.

Read [Handoff V32](../Handoff-v32.md), retain earlier privacy/storage/classroom-method contracts and follow the mandatory [release checklist](RELEASE-CHECKLIST.md). This preference does not authorize unrelated redesigns or data migrations.
