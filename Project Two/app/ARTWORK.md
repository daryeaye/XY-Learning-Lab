# Generated artwork prompts

Mode: built-in image_gen. Each asset is newly generated. No source files modified.

Final output assets are in outputs/playground-lab/assets. Office/lawn: 1672 × 941 RGB. Merry-go-round: 1536 × 1024 RGBA. Volleyball/seesaw: 1774 × 887 RGBA. Transparency checked with pixel-alpha sampling. The merry-go-round's preview glow is RGB under alpha zero and is invisible when composited normally; use the original generation as final.

## Discarded merry-go-round variants
Two additional built-in attempts were made before checking alpha numerically: one background-extraction edit requesting removal of the apparent glow while preserving the sprite, and one new flatter matte sprite explicitly requesting no glow/haze/shadow. Neither replaces the original final, because the original is already alpha-transparent; their RGB previews caused the misleading appearance. Variants remain only in generated_images and are not referenced by the app.
