Generated with the built-in image-generation tool; no CLI/API fallback and no scripted art edits. JPEG copies are format conversions of the native generated PNGs (quality 97, chroma subsampling disabled). Source images remain unchanged.

### Process and prompts

1. Restyle the normal office composition using the original boss sprite as style reference. Preserve right-side character placement, desk hiding the lower body, open left half, all furniture/props and warm colors. Redraw the entire room and character on one coarse pixel grid, approximating a 334×188 native canvas enlarged to 1672×941. Require square pixel clusters, stepped outlines, 2–4 shades per material, no text or added objects.
2. Targeted refinement: strengthen coarseness to a virtual 256×144 canvas enlarged to 1672×941. Request 6–7 output pixel blocks across face, glasses, hair, foliage, window, wood and shadows. Replace gradients with flat color bands and retain composition.
3. Happy variant: edit only the character using the refined normal base and the approved happy JPG as pose reference. Closed smiling eyes, joyful open mouth, raised arms; retain the coarse grid and all room geometry.
4. Surprised variant: edit only the character using the refined normal base and approved surprised JPG as pose reference. Wide green eyes, O-shaped mouth, hands on cheeks; retain the coarse grid and room geometry.
